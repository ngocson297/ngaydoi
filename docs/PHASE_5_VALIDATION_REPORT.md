## Environment limitation

The artifact environment could not complete `npm install` from the public npm registry because registry requests timed out. Therefore, full NestJS/Next.js framework build and Docker-backed migration/smoke execution must be confirmed on the user's machine.

## Required release gate on the user's machine

Run in this order:

```bash
npm install
npm run db:setup
npm run build
```

Start API, then run:

```bash
npm run guest:smoke
```

Phase 5 passes the delivery gate only after these commands complete successfully.

## Expected data-safety behavior

- Do not run `db:clean` during upgrade.
- Phase 5 migration is additive.
- Seed deletes only guests tagged `seed-demo`.
- Uploaded media continues to use the shared `ngaydoi-local-data/uploads` directory.
